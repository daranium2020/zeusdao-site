# ZEUS DAO Limited — zeusdao.io

Lightweight static corporate website for ZEUS DAO Limited.

The site is intentionally minimal and corporate. It does not publish fundraising data, token information, valuation figures, traction metrics, testnet statistics, roadmap details or other investor-material content.

## Files
- `index.html` — main site
- `privacy.html` — privacy notice
- `favicon.svg`
- `robots.txt`
- `sitemap.xml`

## Local preview
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.

## Deploy
Works as-is on Vercel, Cloudflare Pages, Netlify, GitHub Pages or any static web host.
